# Semana-05-Objetos-Dados-e-Assincronismo-Desenvolvimento-Web
Finalização do mini projeto de consumo de APIs e manipulação dinâmica do DOM, aplicando os conceitos de objetos, arrays, assincronismo (Promises, async/await), Fetch API e os quatro estados de uma tela (Carregando, Erro, Vazio, Sucesso). O projeto deve ser entregue em um repositório no GitHub contendo os arquivos index.html e app.js.
